# معلومات الحاسوب البعيد

اطّلع على تفاصيل الحاسوب الآخر دون مغادرة الجلسة: اسمه، وإصدار Windows، والمعالج، والذاكرة، والأقراص ومساحتها الحرة، ومدة تشغيله.

## فتح اللوحة

1. في شريط أدوات الجلسة انقر **معلومات الجهاز**.
2. تسأل اللوحة الحاسوب الآخر وتمتلئ بعد ثوانٍ قليلة (أو فورًا على شبكة سريعة).
3. انقر **تحديث** لتسأل من جديد، مثلًا لترى المساحة المتبقية على القرص بعد نسخ ملفات.

تعرض اللوحة:

| السطر | المعنى |
|---|---|
| اسم الحاسوب | اسم الحاسوب البعيد |
| النظام / الإصدار | إصدار Windows ورقم البناء |
| المعالج / مسارات المعالجة | طراز المعالج وعدد المعالجات المنطقية |
| الذاكرة | حجم الذاكرة المثبّتة |
| مدة التشغيل | الوقت منذ بدء تشغيل الحاسوب |
| الأقراص | شريط لكل قرص: المساحة المستخدمة، و«كذا متاح من كذا» |

تتبع الأحجام والأرقام إعداد الأرقام لديك (أرقام هندية ووحدات عربية عندما تكون الواجهة بالعربية). وتظهر الأسماء العربية صحيحة حتى لو اختلطت بالإنجليزية.

إذا لم يُجب الحاسوب الآخر خلال عشر ثوانٍ تذكر اللوحة ذلك؛ على الأرجح يعمل بإصدار أقدم من TLP-Desk لا يدعم هذه الميزة.

## الصلاحية

كل من يستطيع **رؤية** الشاشة يستطيع قراءة هذه المعلومات، فلا تحتاج صلاحية إضافية. تعرض اللوحة حقائق عن الجهاز والنظام فقط؛ ولا تعرض أبدًا ملفات أو حسابات أو كلمات مرور أو عنوان الشبكة.

## من سطر الأوامر

<div dir="ltr">

```powershell
TLP-Desk-cli info 123456789 --code 042917
TLP-Desk-cli info 123456789 --code 042917 --json
```

</div>

صيغة `--json` تطبع كائنًا واحدًا فيه الحقل `type` بقيمة `device_info`.
