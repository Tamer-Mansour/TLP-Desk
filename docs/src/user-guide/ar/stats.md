# لوحة الإحصاءات

![الجلسة مع لوحة الإحصاءات](../../media/session-ar-light.png)

يُظهر زر **الإحصاءات** في شريط أدوات الجلسة (أيقونة خط النبض) لوحة صغيرة فوق الصورة أو يخفيها (في
الزاوية العليا اليسرى في الواجهة العربية، واليمنى في الإنجليزية). تكون اللوحة ظاهرة افتراضيًا وتتحدث
كل ثانية.

| السطر | معناه | القيمة المعتادة على شبكة جيدة |
|---|---|---|
| **معدل الإطارات** | عدد الصور التي تستقبلها وتعرضها في الثانية (إطار/ث) | حتى ٦٠ أثناء تغيّر الشاشة، وقرابة الصفر حين لا يتحرك شيء |
| **زمن الاستجابة** | تقدير للتأخير بين تغيّر الشاشة البعيدة وظهور الصورة عندك (م.ث) | من ٥ إلى ٣٠ عبر الكابل، وأكثر عبر Wi-Fi |
| **معدل البيانات** | حجم بيانات الشبكة المستخدمة للصورة (ميغابت/ث) | بضعة ميغابتات، وقد يصل إلى نحو ١٥ عند الحركة السريعة على كامل الشاشة |
| **الدقة** | حجم الصورة المرسَلة | حجم الشاشة البعيدة، وبحد أقصى 1920 × 1200 |
| **المدة** | مدة الجلسة حتى الآن | |

## كيف تقرأ الأرقام

- **انخفاض معدل الإطارات حين لا يتحرك شيء أمر طبيعي**: لا يرسل TLP-Desk صورة جديدة إلا حين تتغير الشاشة.
- **زمن الاستجابة** تقدير، ولا يشمل الوقت الذي تحتاجه شاشتك لعرض الصورة، فالتأخير الفعلي أعلى قليلًا.
- إذا انخفض معدل الإطارات وبقي زمن الاستجابة منخفضًا، فهذا يعني أن TLP-Desk يتخطى بعض الصور عمدًا
  ليبقى التأخير قصيرًا، فهو لا يسمح بتراكم الصور أبدًا. والسبب المعتاد شبكة Wi-Fi مزدحمة أو حاسوب بطيء
  في أحد الطرفين.
- إذا تجاوز زمن الاستجابة نحو ١٠٠ م.ث فانظر [حل المشكلات](troubleshooting.md).
