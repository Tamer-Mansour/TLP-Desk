# سجل الاتصالات

![سجل الاتصالات](../../media/connection-log-ar-light.png)

يحتفظ TLP-Desk بسجل محلي لمن اتصل بهذا الحاسوب وللأجهزة التي عرضها هذا الحاسوب. افتحه من **سجل
الاتصالات** في الشاشة الرئيسية أو من قائمة منطقة الإشعارات. السجل لا يغادر حاسوبك أبدًا.

يعرض كل سجل اسم الجهاز ومعرّفه والاتجاه (وارد أو صادر) والتاريخ والوقت والعنوان وطريقة التفويض (طلب
القبول أو الرمز لمرة واحدة أو كلمة المرور) ومدة الجلسة والصلاحيات التي امتلكتها وسبب الانتهاء: أنهاها
أحد الطرفين، أو سُحبت الصلاحية، أو انقطع الاتصال، أو محاولة مرفوضة (رُفض الطلب، لم يُرَدّ عليه، رمز أو
كلمة مرور خاطئة، محاولات كثيرة، غير مسموح بحسب إعداداتك).

- **البحث** يطابق الأسماء (العربية أيضًا) والمعرّفات والعناوين وبصمات المفاتيح. يمكن كتابة المعرّف
  بمسافات أو بدونها وبالأرقام 0-9 أو الهندية.
- تعرض المرشّحات **الكل** أو **وارد** أو **صادر** أو المحاولات **المرفوضة** فقط.
- **تصدير CSV** يحفظ كل السجلات في ملف مناسب للجداول (UTF-8، وتُفتح العربية صحيحة في Excel).

الملف هو `%APPDATA%\TLP-Desk\connections.log` بمعدل سجل JSON واحد في كل سطر. وعندما يتجاوز حدًّا
للحجم يُدوَّر إلى `connections.log.1` ثم `.2` وهكذا ويُحذف الأقدم، فلا يمتلئ القرص أبدًا.
