# Clipboard sharing

> **Coming soon.** This feature is planned but not available yet. It is part of **M2 — Daily-driver features, Lane A** in the [roadmap](https://github.com/Tamer-Mansour/TLP-Desk/blob/TLP-Desk/ROADMAP.md).

## What it will do

Copy on one PC and paste on the other:

- **text** (Arabic text exactly as copied, including direction marks), **images** and formatted (HTML) content, in both directions;
- **files**: copy files in File Explorer on one PC and paste them in File Explorer on the other.

Needs the **Clipboard** permission (and **Files** for copied files).

## Status

The messages for text, images, HTML and copied files are defined in protocol v4.

## Until then

Today Ctrl+C and Ctrl+V work *inside* the remote PC (they are sent as key presses), but the two clipboards are separate.
