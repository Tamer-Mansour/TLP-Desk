# Address book

> **Coming soon.** This feature is planned but not available yet. It is part of **M2 — Daily-driver features, Lane D** in the [roadmap](https://github.com/Tamer-Mansour/TLP-Desk/blob/TLP-Desk/ROADMAP.md).

## What it will do

Save the PCs you use often: aliases, groups, last seen, and whether each one is online right now. Device names in Arabic will be supported.

Not started.
