# Remote device information

> **Coming soon.** This feature is planned but not available yet. It is part of **M4 — Power features** in the [roadmap](https://github.com/Tamer-Mansour/TLP-Desk/blob/TLP-Desk/ROADMAP.md).

## What it will do

A panel with the remote PC's details: Windows version, processor, memory, disks and free space, uptime and name.

## Status

The device information messages are defined in protocol v4.

## Until then

Open **Settings → System → About** on the remote PC during the session.
