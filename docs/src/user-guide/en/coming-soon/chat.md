# Chat

> **Coming soon.** This feature is planned but not available yet. It is part of **M2 — Daily-driver features, Lane D** in the [roadmap](https://github.com/Tamer-Mansour/TLP-Desk/blob/TLP-Desk/ROADMAP.md).

## What it will do

A chat panel inside the session, so the viewer and the person at the host can write to each other — with full Arabic support (shaping, right-to-left message bubbles).

Needs the **Chat** permission.

## Status

The chat message is defined in protocol v4.

## Until then

Talk by phone, or open Notepad on the remote PC and type there.
