# Chat

Write to the person at the other computer during a session — in Arabic, English or both.

## As the viewer

1. In the session toolbar, click the **Chat** button (speech bubble). The chat panel opens at
   the side of the remote screen. A red number on the button counts messages you have not read.
2. Type in the box at the bottom. **Enter** sends, **Shift+Enter** starts a new line.
3. Your messages appear on one side, the other person's on the other. Each message is aligned by
   its own language: an Arabic message reads from the right even in the English interface, and an
   English one from the left in the Arabic interface. Right-click a message to copy it.

While the chat box has the keyboard, your typing stays in the chat and is not sent to the remote
PC. Click the remote screen to control it again.

## As the person at the host

When the viewer writes, a chat window opens on your screen and the TLP-Desk taskbar button
flashes. Reply in the same way. The **Chat** button in the "is connected to this device" banner
opens and closes the window.

**Turn off chat** in the chat window stops the conversation for that session at once, in both
directions; **Allow chat** turns it back on.

## Good to know

- Chat needs the **Chat** permission, which TLP-Desk gives by default to viewers you accept.
- A message can be up to 4000 characters. Sending very many messages in a row is slowed down.
- Messages are kept only while the session is open. Nothing is saved to disk and nothing leaves
  your local network.
- From the command line: `TLP-Desk-cli chat <target> "message"` (see
  [Command line](../command-line.md)).
