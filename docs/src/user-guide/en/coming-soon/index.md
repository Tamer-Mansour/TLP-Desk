# Coming soon

These features are planned and are being built in the order of the
[roadmap](https://github.com/Tamer-Mansour/TLP-Desk/blob/TLP-Desk/ROADMAP.md). None of them is
available in the current version. Each page explains what the feature will do and what you can do
until it arrives.

| Feature | Milestone |
|---|---|
| [Sound from the remote PC](audio.md) | M2 |
| [Address book](address-book.md) | M2 |
| [Unattended access](unattended-access.md) | M3 |
| [Ctrl+Alt+Del and lock](ctrl-alt-del.md) | M3 |
| [Privacy mode](privacy-mode.md) | M3 |
| [Wake-on-LAN](wake-on-lan.md) | M4 |

## Permissions

Every one of these features will have its own **permission**. Accepting a connection today allows
only viewing and controlling the mouse and keyboard; features such as files, clipboard, sound or
restarting the PC will each have to be allowed separately by the person at the host, who will be
able to withdraw them during the session.
