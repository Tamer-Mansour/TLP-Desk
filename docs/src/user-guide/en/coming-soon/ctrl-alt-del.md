# Ctrl+Alt+Del and lock

> **Coming soon.** This feature is planned but not available yet. It is part of **M3 — Unattended access** in the [roadmap](https://github.com/Tamer-Mansour/TLP-Desk/blob/TLP-Desk/ROADMAP.md).

## What it will do

A toolbar button that sends **Ctrl+Alt+Del** to the remote PC (pressing the keys yourself always acts on your own PC), and a button to **lock** the remote PC.

Needs the **System** permission.

## Status

**Lock remote PC** already works from the toolbar's System menu (see [Unattended access](../unattended-access.md)). The **Ctrl+Alt+Del** button is in the menu too, but it requires the TLP-Desk Windows service, which is not available yet.

## Until then

Ask the person at the remote PC, or use the remote PC's Start menu to lock or sign out.
