# Privacy mode

> **Coming soon.** This feature is planned but not available yet. It is part of **M3 — Unattended access** in the [roadmap](https://github.com/Tamer-Mansour/TLP-Desk/blob/TLP-Desk/ROADMAP.md).

## What it will do

While you work on a remote PC, **blank its physical screen and block its local keyboard and mouse**, so people near that PC cannot watch or interfere — useful when working on your own PC from another room.

Needs the **Privacy mode** permission; the host must allow it explicitly.
