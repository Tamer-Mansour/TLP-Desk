# Port forwarding (tunnels)

> **Coming soon.** This feature is planned but not available yet. It is part of **M4 — Power features** in the [roadmap](https://github.com/Tamer-Mansour/TLP-Desk/blob/TLP-Desk/ROADMAP.md).

## What it will do

Reach a network service on or near the remote PC through the session — for example open a web page served by the remote PC on your own browser — without changing any router settings.

Needs the **Tunnel** permission.

## Status

Tunnel messages and tunnel streams are defined in protocol v4.
