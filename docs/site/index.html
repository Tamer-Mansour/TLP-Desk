Remote desktop for your own network. Nothing leaves it.

TLP-Desk lets one Windows PC see and control another on the same local network. It is free, open source and written in Rust. No cloud, no account, no relay server, no telemetry. It keeps working with the internet cable unplugged.

Download for Windows Read the documentation

What you get

One small app is both the PC being controlled (the host) and the PC in control (the viewer).

Offline and LAN-only

Devices find each other automatically on your network, or you type an ID or IP address. By default only private and link-local addresses can connect.

Encrypted and authenticated

Every session uses QUIC with TLS 1.3. The 9-digit device ID is derived from the device's key, so connecting by ID pins its identity. A changed key is a loud warning.

You decide who gets in

Click Accept on the host, enter a one-time 6-digit code, or use a permanent password for unattended access. Passwords never cross the network, and attempts are rate limited.

Smooth video

About 60 frames per second of H.264 video. When the network falls behind, frames are dropped instead of queued, so lag does not build up.

Full control

Mouse, wheel and keyboard, including Win, Alt+Tab and the language switch keys. Switch between the host's monitors live. The person at the host always has priority.

Files, clipboard, chat, sound

Fast file transfer with a remote file browser, clipboard sync for text, images and files, a chat, and the remote computer's sound.

Unattended access

An optional Windows service keeps the PC reachable at the lock and sign-in screens, and reconnects after a restart.

Privacy and tools

Privacy mode blanks the host's screen during a session. Draw on the screen, forward a port, wake a sleeping PC, and review the connection log.

Arabic first

The whole interface is available in Arabic with a mirrored right-to-left layout, joined letters, correct mixed Arabic/English order, Arabic-Indic digits, and Arabic text fields that behave while you type.

Connect in three steps

  1. On the PC you want to control, open TLP-Desk and note its device ID and one-time code.
  2. On your PC, pick it from Devices on this network, or type its ID or IP address.
  3. Enter the code, or leave it empty and click Accept on the other PC. You are in.

English and Arabic, side by side

The same session in both languages: the toolbar and overlays mirror in Arabic.

Download

Get the latest release from GitHub Releases:

  • TLP-Desk-<version>-setup.exe: installer (Arabic and English) that also adds Windows Firewall rules for private networks only.
  • TLP-Desk-<version>-win-x64-portable.zip: no installation; unzip and run TLP-Desk.exe.
  • SHA256SUMS.txt: checksums to verify your download.
